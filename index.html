HOW IT WORKS

Four moves, no magic.

A recipe file plus a run directory. Plain tools like cat, jq, and tail -f work on a live run.

01

Recipe

One TOML file describes the swarm: the agents, their commands, timeouts, and environment.

02

Bake

One command launches the agents in the background, in waves capped by max_parallel. It returns immediately.

03

Supervise

A detached supervisor tracks every agent and kills runaways on timeout. Every log, exit code, and timestamp lands in the run directory.

04

Collect

Merge every agent's output into a single markdown report with bake collect. Done.

QUICKSTART

In the oven in a minute.

Python 3.11 or newer. Nothing else to install.

bakery
$ python -m bakery init            # scaffold an example recipe
$ python -m bakery run hello.toml  # bake off the swarm
$ python -m bakery status <run-id>  # watch it converge
$ python -m bakery logs <run-id> analyzer-3
$ python -m bakery collect <run-id> --format markdown
$ python -m bakery kill <run-id>   # kill a runaway swarm

SECURITY

The oven door stays shut.

Security is non-negotiable. Workers never touch your credentials, and nothing leaks between agents.

Sandboxed agents

Agents run with least privilege. A worker never gets your credentials, tokens, or private keys.

Secrets stay sealed

Nothing is pasted across agent boundaries. If a task needs a credential, the supervisor injects it at the narrowest scope, or the task does not run.

Everything logged

Every agent action is recorded. bake logs answers who did what, when, for any run.

Reports sanitized

Cross-agent traffic is treated as untrusted. Merged output is validated and sanitized at collection time.

FAQ

Asked, answered.

What is Bakery?+

Bakery is a command-line tool that orchestrates parallel agents. You describe a swarm in one recipe file; Bakery launches the agents, supervises them, and merges their output into a single report.

What do I need to install?+

Nothing beyond Python 3.11 and the source. Bakery is stdlib only: no dependencies, no daemon, no cloud.

Do agents get my credentials?+

No. Agents run sandboxed with least privilege. Secrets are never pasted across agent boundaries; a credential is injected at the narrowest scope or the task does not run.

Can Bakery run Kite, Claude, and Gemini as agents?+

Not yet. That is the roadmap: pluggable adapters behind one run and collect interface. Today the shell backend runs commands as agents.

Where do results live?+

In a run directory with per-agent logs, exit codes, and timing. bake collect merges everything into one markdown report.
